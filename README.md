# 🚀 Rahman CLI

**Rahman CLI** is a modern, lightweight, extensible command-line interface built for **Termux** and **Linux**. It helps developers quickly create projects, manage templates, build applications, run projects, manage plugins, generate documentation, and automate development workflows.

---

# ✨ Features

- 🚀 Create new projects from templates
- 🏗️ Build projects
- ▶️ Run projects
- 🔍 Auto project detection
- 📦 Package installer
- 🔌 Plugin Manager
- 🧩 Extension SDK
- 🛒 Marketplace Support
- 📄 Documentation Generator
- 💾 Backup & Restore
- 📝 Logging System
- 🎨 Theme Engine
- ⚙️ Configuration Manager
- 🔒 Security Scanner
- 🩺 Doctor System
- 🔄 Update Checker
- 🏷️ Release Manager
- 📋 Workflow Support
- 📂 Project Manifest (`rahman.json`)
- ⚡ Fast and lightweight
- ❤️ Open Source

# 📦 Installation

Clone the repository:

```bash
git clone https://github.com/rahman2008-svg/RahmanCLI.git
```

Go to the project:

```bash
cd RahmanCLI
```

Run installer:

```bash
chmod +x install.sh
./install.sh
```

Verify installation:

```bash
rahman version
```

# 🔧 Main Commands

## General

```bash
rahman help
rahman version
rahman about
rahman doctor
rahman info
```

---

## Project

```bash
rahman new flask BlogAPI
rahman new python MyApp
rahman detect
rahman build
rahman run
rahman clean
rahman test
```

---

## Package

```bash
rahman install git
rahman install python
rahman uninstall git
```

---

## Plugin

```bash
rahman plugin list
rahman plugin create flutter
rahman plugin remove flutter
```

---

## Extension SDK

```bash
rahman sdk list
rahman sdk create weather
rahman sdk remove weather
```

---

## Marketplace

```bash
rahman marketplace list
rahman marketplace search flask
rahman marketplace install flask-api
```

---

## Configuration

```bash
rahman config
rahman config get
rahman config set theme dark
```

---

## Theme

```bash

rahman theme default
```
